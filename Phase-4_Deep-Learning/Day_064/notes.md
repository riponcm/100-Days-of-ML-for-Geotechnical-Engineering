## Concepts Covered

- nn.Module and defining network architecture
- Linear layers, activation functions, and forward method
- Loss functions: MSELoss, CrossEntropyLoss
- Optimizers: SGD, Adam, and learning rate scheduling
- Training loop: forward pass, loss, backward pass, optimizer step

## Key Takeaways

1. PyTorch's nn.Module provides a clean, modular way to define neural network architectures of any complexity.
2. The training loop pattern (forward, loss, backward, step) is consistent across all PyTorch models.
3. Choosing the right loss function and optimizer significantly impacts training speed and final model quality.

## Code Summary

- Built a simple feedforward neural network in PyTorch for soil property prediction, implemented the training loop, and evaluated on test data

## Geotechnical Application

- Training a neural network to predict continuous geotechnical properties (e.g., undrained shear strength, settlement) from input features
