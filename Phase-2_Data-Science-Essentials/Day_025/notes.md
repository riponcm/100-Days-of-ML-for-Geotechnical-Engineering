## Concepts Covered

- Seaborn's high-level plotting API and integration with Pandas
- Distribution plots: histplot, kdeplot, boxplot, violinplot
- Relational plots: scatterplot, lineplot with hue/style encoding
- Categorical plots: barplot, stripplot, swarmplot
- Pair plots and heatmaps for correlation analysis

## Key Takeaways

1. Seaborn's hue parameter makes it easy to visualize how soil properties vary across different classification groups.
2. Pair plots provide an instant overview of relationships between all numerical soil parameters simultaneously.
3. Correlation heatmaps quickly identify which geotechnical parameters are strongly related, guiding feature selection for ML.

## Code Summary

- Created pair plots of geotechnical parameters colored by soil classification, built correlation heatmaps, and used box plots to compare property distributions across soil types

## Geotechnical Application

- Statistical visualization of soil property relationships and distributions for exploratory analysis of site investigation databases
