## Concepts Covered

- Plotly Express for rapid interactive visualization
- Interactive scatter, line, bar, and 3D plots
- Hover tooltips, zoom, pan, and click events
- Plotly Graph Objects for fine-grained customization
- Exporting interactive HTML plots and embedding in notebooks

## Key Takeaways

1. Interactive plots allow stakeholders to hover over data points and explore borehole data without regenerating static figures.
2. 3D scatter plots are useful for visualizing spatial distributions of soil properties across a site.
3. Plotly integrates well with Jupyter notebooks, making it ideal for exploratory geotechnical data analysis.

## Code Summary

- Created interactive borehole profile plots with hover information, built a 3D scatter plot of borehole locations, and generated interactive cross-sections

## Geotechnical Application

- Building interactive site investigation dashboards where engineers can explore spatial data, hover over boreholes, and filter by soil parameters
