## Concepts Covered

- Pandas Series: creation, indexing, and vectorized operations
- DataFrame construction from dictionaries, CSV files, and NumPy arrays
- Selecting data with .loc[], .iloc[], and conditional filtering
- Basic descriptive statistics with .describe(), .info(), .value_counts()
- Setting and resetting indices

## Key Takeaways

1. DataFrames provide a tabular structure ideal for organizing heterogeneous geotechnical data (depths, soil types, test results).
2. Label-based (.loc) and position-based (.iloc) indexing offer flexible and readable data access patterns.
3. Built-in statistical methods make it easy to quickly profile a dataset before deeper analysis.

## Code Summary

- Created DataFrames representing borehole logs with columns for depth, SPT-N, soil type, and water content, and practiced slicing, filtering, and summarizing geotechnical field data

## Geotechnical Application

- Organizing and querying site investigation databases, borehole logs, and laboratory test result tables using structured DataFrames
