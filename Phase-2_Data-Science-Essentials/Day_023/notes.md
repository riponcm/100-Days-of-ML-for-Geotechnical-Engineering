## Concepts Covered

- Figure and Axes objects in Matplotlib's object-oriented API
- Line plots, scatter plots, bar charts, and histograms
- Customizing labels, titles, legends, and colors
- Saving figures in multiple formats (PNG, PDF, SVG)
- Plotting conventions for geotechnical data (depth on y-axis, inverted)

## Key Takeaways

1. The object-oriented API (fig, ax = plt.subplots()) provides more control and is preferred over the pyplot procedural interface.
2. Inverting the y-axis is essential for geotechnical plots where depth increases downward.
3. Clear labeling with units is critical in engineering plots to avoid misinterpretation.
