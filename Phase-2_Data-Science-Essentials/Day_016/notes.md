## Concepts Covered

- Creating NumPy arrays (1D, 2D, 3D) from lists, ranges, and built-in functions
- Array indexing, slicing, and boolean masking
- Vectorized operations and broadcasting rules
- Reshaping, stacking, and splitting arrays
- Universal functions (ufuncs) for element-wise computation

## Key Takeaways

1. NumPy arrays are significantly faster than Python lists for numerical computation due to contiguous memory layout and C-level operations.
2. Broadcasting eliminates the need for explicit loops when performing operations on arrays of different shapes.
3. Boolean masking enables powerful data filtering, which is essential for extracting subsets of geotechnical measurements.

## Code Summary

- Built arrays representing soil layer depths, SPT blow counts, and moisture content values
- Demonstrated vectorized arithmetic for unit conversions and statistical summaries
- Applied boolean masks to filter data by threshold criteria

## Geotechnical Application

- Storing and manipulating borehole log data (depth, N-values, water content) as structured arrays for efficient batch processing and analysis
