## Concepts Covered

- GroupBy mechanics: split-apply-combine paradigm
- Aggregation functions: sum, mean, count, std, custom functions
- Multi-level grouping and hierarchical indices
- Transform and filter operations on groups
- Pivot tables and cross-tabulations

## Key Takeaways

1. GroupBy enables stratified analysis of geotechnical data by soil type, depth interval, or borehole location in a single operation.
2. Custom aggregation functions allow computing domain-specific statistics like corrected SPT values per soil layer.
3. Pivot tables provide a quick way to summarize large site investigation datasets into decision-ready formats.

## Code Summary

- Grouped borehole data by soil type and depth intervals to compute layer-averaged properties, applied custom aggregation, and created pivot tables

## Geotechnical Application

- Summarizing soil properties by stratum across a site, computing mean and variability of parameters grouped by soil classification
