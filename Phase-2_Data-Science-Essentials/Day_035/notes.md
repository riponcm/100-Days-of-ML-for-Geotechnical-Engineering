## Key Takeaways

1. Real borehole data requires extensive cleaning: inconsistent formats, missing entries, and refusal values need careful handling.
2. SPT-N values typically increase with depth, but stratification and soil type transitions create distinct patterns worth identifying.
3. Combining all Phase 2 skills into a single workflow demonstrates practical data science for geotechnics.
