## Concepts Covered

- Structured EDA workflow: understand, clean, explore, visualize, summarize
- Univariate, bivariate, and multivariate analysis techniques
- Distribution analysis and normality testing
- Correlation analysis and feature relationships
- Automated EDA tools (pandas-profiling / ydata-profiling)

## Key Takeaways

1. A systematic EDA workflow prevents jumping to modeling before understanding data quality and structure.
2. Bivariate analysis reveals which soil parameters are predictive of target variables, guiding model feature selection.
3. Automated profiling tools provide a comprehensive first-pass overview but should not replace domain-informed exploration.

## Code Summary

- Performed a complete EDA on a geotechnical site investigation dataset, generated distribution plots, correlation matrices, and identified key feature relationships

## Geotechnical Application

- Conducting systematic exploratory analysis of site investigation databases before building predictive models for soil properties
