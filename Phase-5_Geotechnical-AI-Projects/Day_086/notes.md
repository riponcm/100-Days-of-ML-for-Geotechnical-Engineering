## Concepts Covered

- SPT-Vs correlation database compilation and preprocessing
- ANN architecture design for Vs prediction
- Ensemble of ANN, Random Forest, and XGBoost for robust prediction
- Uncertainty quantification through ensemble disagreement
- Validation against published empirical correlations

## Key Takeaways

1. Ensemble methods combining neural networks with tree-based models provide more robust Vs predictions than any single model.
2. Uncertainty estimates from ensemble disagreement help engineers assess prediction reliability for each site.
3. Comprehensive validation against multiple published correlations ensures the model is trustworthy for engineering practice.

## Code Summary

- Built an ensemble model combining ANN, RF, and XGBoost for SPT-to-Vs prediction, quantified uncertainty, and validated against empirical correlations

## Geotechnical Application

- Predicting shear wave velocity from SPT data for seismic site classification and ground response analysis when direct Vs measurements are unavailable
