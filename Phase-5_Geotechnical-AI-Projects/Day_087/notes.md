## Concepts Covered

- Spatial liquefaction susceptibility assessment framework
- Deep learning for spatial hazard mapping
- Input features: geology, groundwater, seismicity, soil properties
- GIS integration and raster data handling
- Model calibration against historical liquefaction observations

## Key Takeaways

1. Deep learning can integrate diverse spatial data layers (geological, hydrological, seismic) for comprehensive liquefaction mapping.
2. Spatial cross-validation prevents information leakage from nearby locations in geographically distributed datasets.
3. Calibrating against historical liquefaction observations from past earthquakes validates the model for future hazard prediction.

## Code Summary

- Developed a deep learning model for regional liquefaction susceptibility mapping, integrated multiple data layers, and validated against historical case histories

## Geotechnical Application

- Creating regional liquefaction hazard maps for urban planning, infrastructure design, and earthquake preparedness
