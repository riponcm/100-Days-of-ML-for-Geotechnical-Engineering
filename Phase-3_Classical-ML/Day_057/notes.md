## Concepts Covered

- Ultimate and allowable bearing capacity concepts
- Traditional bearing capacity equations (Terzaghi, Meyerhof, Hansen)
- Feature engineering from soil parameters and foundation geometry
- Training regression models for bearing capacity prediction
- Sensitivity analysis using partial dependence plots

## Key Takeaways

1. ML can predict bearing capacity accounting for complex interactions between soil properties and foundation geometry.
2. Partial dependence plots reveal how individual features influence bearing capacity predictions, enabling engineering validation.
3. Combining ML predictions with engineering judgment and safety factors maintains the reliability required in foundation design.

## Code Summary

- Built bearing capacity prediction models from a dataset of load tests, compared with classical equations, and performed sensitivity analysis

## Geotechnical Application

- Predicting foundation bearing capacity using ML trained on load test databases, supplementing traditional empirical and analytical methods
