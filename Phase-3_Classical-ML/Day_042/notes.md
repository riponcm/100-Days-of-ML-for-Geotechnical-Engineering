## Concepts Covered

- Ensemble learning: bagging and bootstrap aggregation
- Random Forest algorithm and random feature subsets
- Out-of-bag (OOB) error estimation
- Feature importance and permutation importance
- Hyperparameter tuning: n_estimators, max_depth, max_features

## Key Takeaways

1. Random Forests reduce overfitting by averaging many diverse decision trees, making them robust on noisy geotechnical data.
2. OOB error provides a built-in validation estimate without needing a separate validation set.
3. Random Forests consistently rank among the top-performing models for tabular geotechnical prediction tasks.

## Code Summary

- Trained a Random Forest for bearing capacity prediction, analyzed feature importance, and compared single tree vs. ensemble performance

## Geotechnical Application

- Predicting geotechnical design parameters with high accuracy and built-in feature importance for understanding which soil properties matter most
