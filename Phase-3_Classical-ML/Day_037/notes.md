## Concepts Covered

- Scikit-Learn's LinearRegression API and fit/predict workflow
- Train-test splitting and model evaluation
- Residual analysis and diagnostic plots
- Assumptions of linear regression and when they break down
- Multiple linear regression with several input features

## Key Takeaways

1. Scikit-Learn abstracts away the optimization details, letting engineers focus on data preparation and model evaluation.
2. Residual analysis reveals whether the linear model assumptions hold for geotechnical data.
3. Multiple regression allows predicting soil properties from several input variables simultaneously.

## Code Summary

- Built a multi-feature linear regression model predicting soil shear strength, performed residual analysis, and evaluated on held-out test data

## Geotechnical Application

- Predicting geotechnical parameters like bearing capacity or settlement from multiple site investigation measurements
