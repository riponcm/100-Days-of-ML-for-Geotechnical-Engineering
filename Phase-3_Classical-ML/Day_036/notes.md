## Concepts Covered

- Linear regression theory: hypothesis, cost function, gradient descent
- Implementing gradient descent from scratch in NumPy
- Normal equation as a closed-form solution
- Learning rate selection and convergence monitoring
- Cost function landscape visualization

## Key Takeaways

1. Implementing linear regression from scratch builds intuition for how gradient descent optimizes model parameters.
2. The normal equation provides an exact solution but becomes computationally expensive for large feature sets.
3. Monitoring the cost function during training reveals whether the learning rate is appropriate.

## Code Summary

- Implemented linear regression with gradient descent from scratch, visualized convergence behavior, and compared with the normal equation solution

## Geotechnical Application

- Predicting continuous soil properties (e.g., undrained shear strength from SPT-N) using the simplest supervised learning approach
