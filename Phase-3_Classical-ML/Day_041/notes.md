## Concepts Covered

- Decision tree algorithm: splitting criteria (Gini, entropy, MSE)
- Tree construction, pruning, and depth control
- Feature importance from tree splits
- Visualizing decision trees for interpretability
- Overfitting prevention with max_depth and min_samples_leaf

## Key Takeaways

1. Decision trees produce interpretable rules that geotechnical engineers can validate against domain knowledge.
2. Feature importance rankings reveal which soil parameters are most informative for classification or prediction.
3. Unpruned trees easily overfit small geotechnical datasets, making depth constraints essential.

## Code Summary

- Built a decision tree for soil classification, visualized the tree structure, extracted feature importance rankings, and demonstrated pruning effects

## Geotechnical Application

- Creating interpretable classification rules for soil type identification that can be validated by experienced geotechnical engineers
