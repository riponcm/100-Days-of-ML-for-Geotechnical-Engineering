## Concepts Covered

- Soil classification systems: USCS, AASHTO, and their features
- Multi-class classification setup for soil type prediction
- Feature importance for soil classification
- Confusion matrix analysis for multi-class problems
- Handling class imbalance in soil type datasets

## Key Takeaways

1. ML classifiers can automate soil classification from index properties, reducing subjectivity in manual classification.
2. Multi-class confusion matrices reveal which soil types are commonly confused, guiding data collection priorities.
3. Proper handling of imbalanced classes ensures that rare soil types are not ignored by the classifier.

## Code Summary

- Trained multi-class classifiers for USCS soil classification, analyzed confusion patterns, and identified the most informative index properties

## Geotechnical Application

- Automating soil classification from laboratory test results to improve consistency and speed of geotechnical data processing
