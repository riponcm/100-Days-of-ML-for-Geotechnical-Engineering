## Concepts Covered

- Bagging, boosting, and stacking ensemble strategies
- Voting classifiers: hard and soft voting
- Stacking with meta-learners for combining diverse models
- Blending and multi-level ensembles
- When ensembles help vs. when they add unnecessary complexity

## Key Takeaways

1. Combining diverse models through ensembling often yields better predictions than any single model on geotechnical datasets.
2. Stacking allows a meta-learner to optimally weight different models, capturing complementary strengths.
3. Ensemble complexity should be justified by meaningful performance gains, especially when model interpretability is important.

## Code Summary

- Built voting, stacking, and blending ensembles for soil property prediction, compared ensemble vs. individual model performance, and analyzed diversity metrics

## Geotechnical Application

- Combining multiple ML models to achieve more reliable and accurate predictions of geotechnical design parameters
