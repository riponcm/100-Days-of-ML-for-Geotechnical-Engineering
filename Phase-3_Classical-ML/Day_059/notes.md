## Concepts Covered

- Cone Penetration Test (CPT) parameters: qt, fs, u2
- Traditional CPT interpretation charts (Robertson, Eslami-Fellenius)
- ML-based soil behavior type classification from CPT data
- Continuous profiling and layer boundary detection
- Advantages of ML over chart-based interpretation

## Key Takeaways

1. CPT provides high-resolution continuous data ideal for ML-based interpretation, unlike discrete SPT measurements.
2. ML models can simultaneously use all CPT parameters (qt, fs, u2, Bq, Fr) for more accurate soil classification.
3. Automated layer boundary detection using ML can process thousands of CPT data points consistently and rapidly.

## Code Summary

- Built ML classifiers for CPT soil behavior type, compared accuracy with Robertson chart classifications, and implemented automated layer detection

## Geotechnical Application

- Interpreting Cone Penetration Test data using machine learning to classify soil behavior type and identify stratigraphic boundaries
