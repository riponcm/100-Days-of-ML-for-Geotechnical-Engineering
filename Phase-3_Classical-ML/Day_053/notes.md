## Concepts Covered

- Tree-based feature importance (Gini, permutation)
- SHAP (SHapley Additive exPlanations) values and theory
- SHAP summary plots, dependence plots, and force plots
- Local vs. global interpretability
- Explaining ML predictions to non-technical stakeholders

## Key Takeaways

1. SHAP values provide theoretically grounded feature attributions that explain why a model made a specific prediction.
2. Feature importance reveals which soil parameters drive model predictions, enabling domain validation of ML models.
3. Explainability is essential for adopting ML in geotechnical practice, where engineers must understand and trust model outputs.

## Code Summary

- Computed SHAP values for a geotechnical prediction model, created summary and dependence plots, and generated local explanations for individual predictions

## Geotechnical Application

- Making ML model predictions transparent and interpretable for geotechnical engineers who need to validate and trust automated predictions
