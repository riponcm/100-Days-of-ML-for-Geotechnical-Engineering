## Concepts Covered

- Logistic regression for binary classification
- Sigmoid function and probability interpretation
- Decision boundary visualization
- Multi-class logistic regression (one-vs-rest, softmax)
- Regularization in logistic regression

## Key Takeaways

1. Logistic regression provides probability estimates for classification, useful for quantifying the likelihood of geotechnical hazards.
2. The sigmoid function maps linear combinations of features to probabilities between 0 and 1.
3. Despite its simplicity, logistic regression often serves as a strong baseline for binary geotechnical classification tasks.

## Code Summary

- Built a logistic regression classifier for soil liquefaction potential, visualized decision boundaries, and interpreted feature coefficients as risk factors

## Geotechnical Application

- Classifying soil conditions (e.g., liquefiable vs. non-liquefiable) and estimating the probability of geotechnical hazards
